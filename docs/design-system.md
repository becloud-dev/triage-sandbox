# Design system (sandbox test)

## Colours
- Primary action: #1F6FEB
- Surface: #FFFFFF
- Text: #1B1F24

## Type
- Body: 16px, system sans-serif
- Page title: 24px, semibold

## Components
- Button: filled with the primary colour for the main action, outlined for secondary
- Page header: title on the left, actions on the right
- Table: header row on the surface colour, one row per record, actions in the last column
